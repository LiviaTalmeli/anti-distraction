Como usar como Extensão no Chrome / Edge

Além de usar este Web App diretamente no navegador, este projeto já inclui a Extensão Oficial Manifest V3 pronta na pasta extension/ para você instalar no seu Chrome ou Edge em 30 segundos:

1
Abra a tela de extensões do seu navegador:
chrome://extensions
2
Ative o "Modo do desenvolvedor"

Fica no canto superior direito da tela de extensões.

3
Clique em "Carregar sem compactação" (Load unpacked)

Selecione a pasta extension/ deste repositório. Pronto! O ícone do Anti-Distraction estará na barra do navegador!
